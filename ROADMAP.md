# Roadmap

Planned work, in order. Phase 1 has shipped.

| Phase | Theme | Outcome |
|---|---|---|
| 1 | Ship it | Windows/macOS/Linux release binaries from CI, app icon, installer, crash-safe autosave + recovery, startup and paint performance pass |
| 2 | Selection pro | Quick Selection (graph-cut), Magnetic Lasso, Select and Mask workspace (refine edge, decontaminate), Quick Mask mode, alpha channels panel, Transform Selection, single row/column marquee |
| 3 | Vector | Paths + Pen tools, vector shape layers (editable), vector masks, Type on path, vertical type, SVG import/export |
| 4 | Non-destructive | Smart Objects, Smart Filters (filter stacks on layers), Pattern fill + Pattern Overlay, Layer Comps, Artboards, layer linking/distribute, enforced locks |
| 5 | Color and photo | ICC color management (lcms2), CMYK and Lab modes, soft proof, 3D LUT (Color Lookup), Camera RAW import with a develop panel, HDR toning, Match/Replace Color, Lens Blur |
| 6 | AI, pluggable | Provider adapters (local ONNX, local ComfyUI, cloud APIs): Generative Fill/Expand, ML Select Subject/Object/Sky, Remove Background, Super Resolution, Neural Filters, Harmonize |
| 7 | Long tail | PSD write, PDF export, Warp + Puppet Warp, Content-Aware Scale, Patch + Content-Aware Move, Mixer Brush, History Brush, Pattern Stamp, Perspective Crop, rulers, Rotate View, custom shortcuts and workspaces, scripting (Rhai) and WASM plugins |
